# Encounter illustrations

Original opaque encounter paintings generated with Amp Painter on 2026-09-20
for The Last Ember. These are full-scene paintings, not enlarged sprite crops.
The existing Act paintings supplied visual references. WebP exports use quality
84 with metadata removed. No text or UI is baked into the artwork.

Combat filenames identify the actual enemy formation in alphabetical order,
including duplicate enemies. Shops and camps have one painting per Act. Eight
story paintings use close settings or interiors suitable for encounters across
Acts. These assets are bundled locally; playing does not call an image service.
